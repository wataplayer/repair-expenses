# Учёт ремонта

Общий журнал расходов на ремонт: дата, сумма, категория, заметка и чек.

Страница: https://wataplayer.github.io/repair-expenses/

Журнал публичный. Кто открыл ссылку, видит те же суммы и чеки и может добавить запись. Страница лежит на GitHub Pages, записи и файлы чеков — в Cloudflare, поэтому ссылка открывается без домашнего компьютера.
